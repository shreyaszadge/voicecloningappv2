Put your own avatar files (.glb) in this folder and they appear in Settings > Avatar.

Optional: add a file called avatars.json here to give them names, for example:
[
  { "file": "me.glb", "name": "My face", "body": "M", "avaturn": true }
]
  body    "M" or "F" (matches the avatar's body)
  avaturn true if the avatar was made at avaturn.me (applies a better head angle and eyelids)

You can also add avatars directly in the browser: Settings > Avatar > "Add my avatar".
